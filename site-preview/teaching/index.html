Teaching

Courses I teach at NPS and have taught elsewhere.

At NPS I teach in the OR department’s computational methods sequence. Practical stuff: get data, clean it, analyze it, automate the boring parts, and use remote or HPC resources without fear. AI coding assistants are in the mix too — with the verification habits you need so they don’t quietly invent things.

Naval Postgraduate School

OA3802 Instructor

Computational Methods for Data Analytics

Fall 2026 (two resident sections); Winter, Summer 2027

Third course in the computational methods sequence. Acquiring, storing, cleaning, and merging data at scales beyond a laptop: the shell and regular expressions, cloud and high-performance computing, parallel and GPU computing, web, geospatial, and unstructured text data, SQL and modern storage engines, reproducible workflows with Git and containers, and large language model APIs and agentic tools used with appropriate verification. A project replaces the final exam.

OA4910 Co-instructor

Python Boot Camp

Summer 2026 (5.5-week boot camp)

Fast-paced applied Python for incoming master's students with no programming background. A data-wrangling spine in pandas, AI-assisted workflows, light prediction, and report automation, ending in a data-to-brief capstone.
