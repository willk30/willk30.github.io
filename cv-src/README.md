Compile with the [Medium Length Professional CV](https://www.latextemplates.com/template/medium-length-professional-cv) `resume` class (EB Garamond). After building the PDF, copy it to:

- `assets/pdf/Kirschenman_CV.pdf` (linked from the CV page)
- `files/Kirschenman_CV.pdf` (legacy path; keep both in sync)

The checked-in `.tex` uses NPS email only. If your personal PDF header includes a street address or phone, keep those off the public site pages.
