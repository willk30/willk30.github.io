# Site redesign mockups (review only)

Three self-contained home-page prototypes for [willk30.github.io](https://willk30.github.io). Not wired into the live Jekyll build yet.

## Open

Serve this folder and open `index.html`:

```bash
cd mockups && python3 -m http.server 8765
# → http://127.0.0.1:8765/
```

| # | Direction | File | Hook |
|---|-----------|------|------|
| 01 | Priority Deck | `01-priority-deck.html` | Interactive packing diagram as the hero |
| 02 | Fog Lab | `02-fog-lab.html` | Editorial + living solver landscape |
| 03 | Landing Waves | `03-landing-waves.html` | Horizontal scroll through three research waves |

All are static HTML/CSS/Canvas — GitHub Pages compatible once we promote a winner into the real theme.
