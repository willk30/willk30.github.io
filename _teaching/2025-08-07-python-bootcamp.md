Selected to design and teach a one-day "Introduction to Python" module for all incoming Ph.D. students in the Department of Industrial and Systems Engineering.

## Course Overview

This intensive one-day module covers fundamental Python programming concepts essential for operations research and data science applications, including:

- Python basics and data structures
- NumPy and pandas for data manipulation
- Visualization with matplotlib
- Introduction to optimization libraries
